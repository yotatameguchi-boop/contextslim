不具合を修正したリリースです。v0.1.0 をお使いの方は更新してください。

## 修正

- 複数のコマンドが同時に実行されたとき（Claude が並行してテストを走らせた場合など）、原文の保存がまれに失敗し、その回の出力が圧縮されないことがあった不具合を直しました。
  - 自動整理が、別の処理が使い始めたばかりの保存フォルダを「空」とみなして削除していたのが原因です。
  - 保存に失敗した場合は原文をそのまま渡す作りのため、出力の内容が欠けることはありませんでした。

## 更新のしかた

実行ファイルを新しいものに置き換えるだけです。置き場所を変えなければ、`contextslim install` をやり直す必要はありません。

```bash
curl -fL -o ~/.local/bin/contextslim https://github.com/yotatameguchi-boop/contextslim/releases/download/v0.1.1/contextslim_v0.1.1_darwin_arm64
chmod +x ~/.local/bin/contextslim
contextslim version
```

URL の末尾は環境に合わせて変えてください（下の表）。

`SHA256SUMS` で改ざんがないか確認できます。
