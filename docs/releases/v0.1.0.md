ContextSlim の最初のリリースです。Claude Code の Bash ツールが返すテスト・型チェック・Lint の出力を、失敗情報を落とさずに短くします。

## できること

- Vitest 3.x / Jest 29.x / tsc 5.x / pytest 8–9 / Ruff 0.17 の出力を圧縮（成功テスト行の集約、同一診断の集約、ANSI カラーの除去）
- 失敗ブロック・エラー・ツール自身の要約行は原文のまま。文字数での切り捨てはしない
- 圧縮前の原文はローカルに保存し、`contextslim show <ID>` で取り出せる
- 失敗したテスト（終了コード≠0）も、ラッパー方式で圧縮（Linux・macOS）
- 初期状態は観測モード（出力は変えずに統計だけ記録）

## 注意

- ラッパー方式は、元のコマンドを Claude Code が確認なしで実行する場合（許可ルールに一致し、拒否・確認ルールに一致しない場合）だけ使われます。
- Windows では失敗時の出力は圧縮しません（終了コード0の出力のみ）。
- 動作確認した Claude Code は 2.1.322 です。

導入手順は [README](https://github.com/yotatameguchi-boop/contextslim#インストールと使い方) を参照してください。
